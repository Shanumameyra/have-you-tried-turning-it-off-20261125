One funny line a hopeless tech support agent gives a desperate customer — an entry for the [make.fun bounty "Have You Tried Turning It Off?"](https://make.fun/bounty/u-motasimfuad-have-you-tried-turning-it-off-154a938b).

## The line

> Have you tried turning it off and on again? The manual's step two is just a drawing of a man shrugging, sir, and step three is me, doing the same.

## How it works

`main.py` writes that single line to `/output/entry.txt` (146 characters, UTF-8), where the judge reads it.

```sh
python3 main.py
cat /output/entry.txt
```
